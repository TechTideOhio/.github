# Support and Contact

## Choose the Right Route

| Need | Best route |
|---|---|
| Install, configure, or use a project | Start with the README and documentation in the affected repository. For Swarm 357, use the [documentation site](https://swarm357.techtideai.io/docs). |
| Report a reproducible bug | Open an issue in the affected repository using its bug-report form or template. |
| Propose an improvement or feature | Open an issue in the affected repository using its feature-request form or template. |
| Contribute a fix or documentation | Read [CONTRIBUTING.md](CONTRIBUTING.md) and the repository’s own contributor instructions. |
| Ask a general, partnership, or business question | Contact TechTide AI through [techtideai.io](https://techtideai.io) or [LinkedIn](https://www.linkedin.com/company/techtide-ai/). |
| Report a vulnerability or security concern | Follow [SECURITY.md](SECURITY.md). Do not create a public issue. |
| Report a community conduct concern | Follow the private reporting process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |

## Support Expectations

Support is primarily provided through project documentation and the issue trackers for the relevant public repositories. When opening an issue, include the affected version or commit, a clear description of the problem, steps to reproduce it, and relevant sanitized logs or screenshots. This information helps maintainers assess and triage requests efficiently.

Repository-specific support policies, service agreements, or maintenance commitments take precedence over this organization-wide guide.
